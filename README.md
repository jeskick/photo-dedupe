# 相片视频查重

在本机查找单反和苹果手机照片、视频里的重复文件，确认后移入回收站。这台电脑用 http://127.0.0.1:8765/ 打开，同一局域网里的设备也可以用这台电脑的局域网地址打开。照片不会上传。页面没有登录，局域网里打开的人可以浏览，也可以把照片移入回收站。

## 环境

只支持 Windows 10 / 11。

- Node.js 20 或更新版本：https://nodejs.org/
- Python 3.12：https://www.python.org/downloads/

Python 用来做画面相似比对，以及 HEIC、TIFF、RAW 的预览。没有 Python 时，字节完全相同的重复文件仍然可以查重。不要安装免 GIL 的 Python（名称里带 free-threading 或 `3.13t`），那些预编译库装不上。人物识别还需要较新的 Microsoft Visual C++ 2015–2022 运行库（系统里要有 `vcruntime140_1.dll`）。`启动.bat` 发现没有时会用 winget 安装；也可以手动装 https://aka.ms/vs/17/release/vc_redist.x64.exe 。只有 2015 年的旧运行库时，`onnxruntime` 会报找不到模块，浏览和查重不受影响。

不需要额外安装 npm 包。

## 在这台或另一台电脑上运行

1. 安装 Node.js 和 Python 3.12。安装 Python 时勾选 “Add python.exe to PATH”。
2. 把这个文件夹拷过去，或克隆仓库：

```bat
git clone https://github.com/jeskick/photo-dedupe.git
cd photo-dedupe
```

3. 双击 `启动.bat`。

第一次运行会在 `.venv` 里安装画面比对所需的库，需要联网，可能要几分钟。完成后浏览器会打开 http://127.0.0.1:8765/ 。黑色窗口里还会打印局域网地址，例如 `http://192.168.1.8:8765/` 。关掉黑色窗口就会停止程序。

也可以在文件夹里手动启动：

```bat
node src\server.js
```

## 使用

左侧「照片管理」会打开另一页。那一页可以在照片和视频之间切换，扫描全部本地磁盘，按拍摄时间排成预览。左侧的时间、来源、标记、星级和扫描可以各自折叠。视频里不显示标记。标记里点「识别全部照片」后，先区分人物、动物和风景，再只对有人的照片认脸，把不同的人分成一组。人和动物同时出现时两边都会标上，室内和车船不会放进风景。左侧显示每个人的张数，点一行再起名；下次识别会自动沿用这些名字。同一段时间里，没脸的照片不多时，背影和轮廓也会跟着这个人。识别只在本机进行，不会据此删除文件。可以记住不扫描的目录，也可以不收录长边太小的文件。记录保存在本机数据库里，下次打开直接显示。再次扫描会补上新文件，并去掉已经不在磁盘上的同一种记录。单击全屏，点照片以外的空白处就关闭。滚轮可以放大照片，左侧能看到拍摄参数，顶栏可以打星或移入回收站；双击打开所在文件夹。悬停缩略图也可以打星，或把文件移入回收站。移入回收站不再询问。

添加要扫描的文件夹，开始扫描。查重和照片库共用排除目录、以及长边太小就不比对。预览不写到磁盘上。每组默认留下一份，勾着「删除」的会进回收站。Windows、Program Files、AppData、游戏目录，以及图标、缓存、表情这类软件目录不会进入查重。盘符和它的一级目录不会因此被整盘跳过；再往下的文件夹里，只要直接放着照片、视频、RAW 和附属文件以外的文件，这一整棵目录都不扫描。同目录同名的 RAW 和 JPG 是一次拍摄的两种格式，不算重复。

换一台电脑继续改这个程序时，先读 `接力.md`。
